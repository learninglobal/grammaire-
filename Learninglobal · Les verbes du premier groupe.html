Les terminaisons
je : -e · tu : -es
il / elle / on : -e
nous : -ons · vous : -ez
ils / elles : -ent
Le -ent des verbes est silencieux.

Garder le son
commencer → nous commençons
manger → nous mangeons
Mais : vous commencez, vous mangez.

Changer la voyelle
j’achète / nous achetons
je préfère / nous préférons
Le radical change avec je, tu, il/elle/on, ils/elles.

Y ou I ?
je paie ou je paye
tu essaies ou tu essayes
je nettoie · j’envoie
nous nettoyons · vous envoyez

Doubler une consonne
j’appelle / nous appelons
je jette / vous jetez
Attention : acheter → j’achète.

Les pronoms
je → j’ devant une voyelle
je m’appelle · tu t’appelles
nous nous appelons
Aller est un verbe du troisième groupe.
